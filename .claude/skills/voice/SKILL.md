# セリフから音声を作る

`scripts/tts.py` が Gemini TTS（`gemini-3.8-flash-tts`、既定の話者 Zephyr）でセリフから WAV を作る。このスキルは、何を作るかを発言から決めてそれを呼び、できた声を鳴らして聞いてもらう。

```
uv run scripts/tts.py "いいえ、違います！" --out assets/sounds/no-1.wav [--voice Zephyr] [--style "きっぱり"] [--takes 3] [--m4a]
```

引数の一覧は `uv run scripts/tts.py --help`。

## 決めること

発言から次を決める。決められないのは **ファイル名だけ** 聞く（セリフが短ければ `no-1`・`yes-80` のように用途から付けてよい）。

| 項目 | 決め方 |
|---|---|
| セリフ | 発言の「『』」や「〜と言わせて」の中身。句読点・「！」もそのまま読まれるので、そのまま渡す |
| 置き場 | ゲームで使う声（「ゲームで使う」と言われた、または名前が `start`・`yes`・`no` のような用途名）→ `assets/sounds/<名前>.wav` に `--m4a` 付き。試しに聞くだけ → scratchpad に `--m4a` なし |
| 話し方 | 「きっぱりした感じで」「明るく」のような言い方があれば、その表現をそのまま `--style` に渡す（縮めたり補ったりしない）。本文には混ぜない（3.8 TTS は本文を一字一句そのまま読む） |
| 話者 | 指定がなければ Zephyr（ゲームの声はこれで揃えている） |
| 本数 | 「何本か」「いくつか作って選ぶ」なら `--takes 3`。指定がなければ 1 本 |

## 実行後

1. できた WAV を `afplay <path>` で 1 本ずつ順に鳴らす（Bash）。複数のときは「1 本目」「2 本目」と言ってから鳴らす。
2. パスと長さ（スクリプトが出す）を伝える。
3. 複数作ったときは、どれを残すか聞く。選ばれなかったものは WAV と m4a（`src/insider_bot/web/static/sounds/<名前>.m4a`）の両方を消し、残すものを枝番なしの名前に戻す。
4. 「読み直して」「もっと明るく」と言われたら、同じ `--out` で `--style` を変えて作り直す（上書きされる）。

## うまくいかないとき

- `GEMINI_API_KEY がありません` → スクリプトの案内（AI Studio で鍵を作って `.env` に書く）をそのまま伝えて止まる。鍵をチャットに貼ってもらわず、`.env` に書いてもらう。
- `生成に失敗しました: ...` → API のメッセージをそのまま伝える。再試行はしない（手作業の道具なので人が判断する）。
- `afconvert が無い` → Mac 以外。WAV だけできている旨を伝える。

## 範囲外

ゲームへの組み込み（`hub.py` で鳴らす・`docs/spec.md` の更新）は別の作業なので、作った声の置き場を伝えて「組み込みは別途」と添える。
