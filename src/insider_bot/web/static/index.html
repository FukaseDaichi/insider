    A SMALL GUIDE TO BIG QUESTIONS

    答えは、会話のなかに。

    1. 01

      仲間とルームに集まる

      ルームを作り、URL や QR を共有。会話には Discord や Zoom などの通話を使います。

    2. 02

      ひとりがお題を決める

      「お題を出す」から秘密の言葉を設定。お題は出題者の画面にだけ表示されます。

    3. 03

      はい・いいえで、絞り込む

      「果物ですか？」のように質問。ボタンを押して話し、離すと送信。文字でも質問できます。

    4. 04

      わかったら、答えを質問する

      「りんごですか？」と聞いて正解を目指そう。ギブアップするとお題を公開して終了します。
